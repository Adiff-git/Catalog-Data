# Media in this package

`images/fixtures/` contains 1,500 original illustrative WebP fixtures generated by `scripts/generate_fixture_images.py`. Each image visibly says “ILLUSTRATIVE FIXTURE” and carries its ASIN label. They provide one stable source identity per Product for development integration; they are not authentic product photos.

`manifests/image_manifest.json` maps each ASIN to Product UUID, relative fixture path, SHA-256, MIME type, size, and dimensions. The source image URL field is provenance for the original catalog record; it is not the source of the packaged fixture bytes. Authentic Amazon-derived preview files remain outside this repository with UNKNOWN rights. Do not copy or upload them under the fixture permission mode.

The Backend importer `tools/catalog-import/amazon_image_import.py --fixture-mode` calls the established Product media upload API. A local checkpoint makes retries resumable. The Backend assigns durable S3 object keys; the database stores object keys, not owner-machine URLs. Browser-facing URLs are signed at runtime using environment-specific storage configuration. The full Docker bootstrap and fresh-clone checks are reserved for Phases 5 and 6.
